# Security policy

This is a fictional portfolio project under active development and is not production deployed.
Do not submit real customer data, tokens, credentials, or confidential knowledge documents.

Report suspected vulnerabilities privately to the repository owner rather than opening a public
issue containing exploit details or secrets. Include affected commit, reproduction steps, and
impact while minimizing copied data.

If a credential is exposed, revoke and rotate it first, then remove it from current files and Git
history as appropriate. Secret scanning is a guardrail, not proof that the repository is safe.
